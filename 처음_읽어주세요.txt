BOXHEAD · BACKROOM CO-OP 1.0

1. ZIP을 모두 압축 해제하세요.
2. 혼자 하기: BOXHEAD.exe 또는 START_BOXHEAD.bat 실행 → 싱글플레이.
3. 친구와 하기: Node.js 20 이상 설치 → START_ONLINE.bat 실행.
   브라우저에서 http://localhost:3000 → 온라인 협동 → 방 만들기.
   친구는 같은 서버 주소에서 방 코드 입력 → 둘 다 준비 → 호스트 시작.

다른 장소의 친구와 하려면 외부 접속 가능한 서버에 배포해야 합니다.
이 ZIP에 운영 중인 공개 서버 주소가 들어 있는 것은 아닙니다.
같은 Wi-Fi에서는 친구가 http://서버PC의내부IP:3000으로 접속합니다.
localhost 주소는 친구에게 공유할 수 없습니다.

기본 조작: WASD 이동 / Shift 달리기 / Space 점프 / 마우스 사격·조준
R 재장전 / E 회복·아군 부활 / F 중계기·정비 준비 / ESC 설정
모바일은 가로 화면의 터치키를 사용합니다.

스토리 모드는 제거했습니다.
10레벨 작전과 보상을 반복하며 10레벨마다 탈출할 수 있습니다.
협동 중 연결이 끊기면 최대 2분 동안 대기하고 같은 탭 새로고침으로 복귀합니다.
