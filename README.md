# BOXHEAD · BACKROOM CO-OP 1.3

저폴리 1인칭 생존 FPS입니다. 싱글플레이와 2인 온라인 협동을 지원합니다.
스토리 캠페인, 챕터 선택, 시네마틱과 관련 코드는 제거했습니다.

## 1.3 업데이트

- **적 디자인**: 6종의 방호복·마스크·방탄판·갈고리·가스통·방패를 서로 다른 실루엣으로 구성했습니다.
- **개별 모션**: 일반형의 절뚝임, 러너의 전력 질주, 탱크의 양팔 내려찍기, 균열술사의 부유·시전, 자폭형의 긴장·경고, 방패형의 방어·밀치기. 피격 반응과 정예 크기도 유지합니다.
- **무기 외형**: 총열·가늠자·탄창·개머리판·레일 코일, 수류탄·지뢰·설치 도구와 화염병 디테일. 발사 시 슬라이드·펌프, 재장전 시 탄창이 움직입니다.
- **모바일**: 양손 간편 / 3·4손가락 / 왼손 발사 배치, 아이콘과 상태 표시, 9칸 직접 무기 선택, 가변 속도 스틱, 화면 가장자리 여백. 기존 사용자 배치는 유지합니다.
- **생존 통신**: 목표 시작·완료, 체력 위험, 아군 쓰러짐·부활, 탈출·패배를 한국어 나레이션과 자막으로 안내합니다.

### 나레이션 켜고 끄기

메인 또는 일시정지 → **사운드 설정 → 생존 통신**에서 나레이션·자막을 각각 켜고 끕니다.
음성 음량과 목소리를 선택하고 **안내 확인**으로 시험할 수 있습니다. 전체 음량도 적용됩니다.
기기의 한국어 읽어주기 음성을 사용합니다. 한국어 음성이 없거나 브라우저가 지원하지 않으면 자막으로 안내하며, 상태 메시지에 이유를 표시합니다.
음성을 추가한 뒤 페이지를 다시 열어 확인하세요. 제공되는 목소리와 재생 가능 여부는 기기·브라우저에 따라 다릅니다.
나레이션은 외부 음성 API 키 없이 동작하며, 기기에 설치된 음성이 있으면 우선 선택합니다.

### 모바일 사용법

- 스틱을 살짝 밀면 천천히 이동하고 위로 끝까지 밀면 자동 달리기합니다. 협동에서도 서버가 같은 아날로그 입력을 적용합니다.
- 오른쪽 빈 화면을 드래그해 시점을 바꾸거나, **발사 버튼을 누른 채 드래그**해 사격과 조준을 함께 합니다.
- **무기 버튼 → 원하는 무기**를 눌러 교체합니다. 잠긴 무기는 해금 레벨을 표시합니다. 창이 열려 있는 동안에도 전투는 진행됩니다.
- **모바일 조작 설정 → 버튼 배치**에서 프리셋을 선택합니다. 사용자별 위치·기능·크기·투명도·감도 설정도 가능합니다.
- 앱 전환·손가락 취소·일시정지 시 누르고 있던 이동·발사 입력을 정리합니다.

서버와 클라이언트는 모두 **1.3.0 / 통신 규격 6**을 사용하세요. 이전 서버는 새 압축본으로 교체 후 재시작해야 합니다.

## 바로 플레이하기

### 혼자 하기 — 인터넷·Node.js 불필요

1. ZIP을 **먼저 모두 압축 해제**합니다.
2. Windows에서는 `BOXHEAD.exe` 또는 `START_BOXHEAD.bat`를 실행합니다.
3. **싱글플레이 → 싱글플레이 시작**을 누릅니다.

다른 운영체제에서는 `client/index.html`을 브라우저에서 열면 됩니다.
Three.js와 게임 코드가 번들에 포함되어 외부 CDN에 의존하지 않습니다.
기존 입력·그래픽 설정과 기록은 같은 브라우저/주소에서 유지됩니다.

### 친구와 하기 — 두 사람이 같은 게임 서버로 접속

1. 서버를 실행할 PC에 **Node.js 22 이상**을 설치합니다.
2. Windows: `START_ONLINE.bat` 실행. macOS/Linux: `./START_ONLINE.sh` 실행.
   첫 실행 때 서버 패키지를 내려받으므로 인터넷 연결이 필요합니다.
3. 서버 PC에서는 `http://localhost:3000`으로 접속합니다.
4. **온라인 협동 → 방 만들기**를 누릅니다.
5. 친구도 같은 서버 주소로 접속해 **6자리 코드 → 입장**을 누릅니다.
6. 두 사람 모두 **준비하기**, 호스트가 **협동 플레이 시작**을 누릅니다.

**서로 다른 장소에서 하려면 외부에서 접속 가능한 Node 서버가 필요합니다.**
이 압축본은 공개 서버를 자동 생성하지 않습니다. `DEPLOYMENT.md`를 참고해
프로젝트를 서버에 올린 다음 그 서버의 HTTPS 주소를 두 사람이 사용하세요.
GitHub Pages에 파일만 올리면 싱글은 가능하지만 협동 서버는 실행되지 않습니다.

같은 Wi-Fi/LAN에서는 친구가 `http://서버PC의내부IP:3000`으로 접속할 수 있습니다.
Windows 방화벽의 해당 포트를 허용해야 할 수 있습니다. `localhost`는 그 PC
자신을 가리키므로 친구에게 공유할 주소가 아닙니다. 방 코드는 같은 서버 안에서만 유효합니다.

## 1.2 추가 기능

- 일반·러너·탱크·균열술사·자폭형·방패형의 숨소리와 공격·사망 목소리를 각각 합성합니다. 설정에서 미리 들을 수 있습니다. 실제 녹음 음원은 사용하지 않습니다.
- 개체마다 집요한 추격·측면 우회·앞길 차단·변칙 접근·신중한 포위 성향을 배정합니다. 속도·접근 간격·우회 방향이 달라지고 밀집 시 서로 비켜갑니다. 좁은 통로에서는 길을 따라 이동하고 열린 공간에서 다시 퍼집니다.
- **레벨 2 해금 / 9번 화염병**: 투척 후 반경 3.6m, 7초 지속 화염. 기본 초당 22 피해와 탈출 후 1.8초 잔불, 중첩 피해 제한, 벽 차폐를 적용합니다. 자기 화염은 초당 5, 협동 팀원은 피해 없음.
- 멀티 화면에 서버 주소 입력·연결·서버 버전·초대 링크 표시를 추가했습니다. LAN 호스트의 초대 주소는 가능한 경우 내부 IP로 변환합니다.

**접속 순서와 외부 서버 배포: [온라인_연결방법.md](온라인_연결방법.md)**

## 레벨 구성

| 레벨 | 작전 | 완료 조건 |
|---|---|---|
| 1 | 구역 확보 | 모든 적 처치 |
| 2 | 기동 제압 | 러너가 섞인 적 전부 처치 |
| 3 | 포위 생존 | 34초 생존 |
| 4 | 감염원 제거 | 코어 2개를 사격·폭발로 파괴 |
| 5 | 중장갑 사냥 | 강화 탱크와 호위 적 처치 |
| 6 | 거점 점령 | 거점 안에서 총 26초 버티기 |
| 7 | 폭발 러시 | 폭발 개체 위주의 적 처치 |
| 8 | 중계기 복구 | 중계기 3개에 접근해 F를 길게 누르기 |
| 9 | 비상 전력 | 어두워진 전장에서 38초 생존 |
| 10 | 균열 지휘체 | 강화 균열술사와 호위 적 처치 |

11레벨부터 같은 작전 순서가 반복되며 적 수·체력·임무 시간 등이 증가합니다.
적 수와 동시 등장 수에는 상한이 있습니다. 5개 전장과 3개 난이도를 선택할 수 있습니다.
연습 시작은 기록에 반영되지 않습니다.

- 필수 목표와 추가 목표를 분리했습니다. 헤드샷/시간 추가 목표를 놓쳐도 진행 가능합니다.
- 코어·거점·중계기는 이동 가능한 구역에 배치되고 거리·방향 표식으로 찾을 수 있습니다.
- 거점에서 벗어나도 점령 진척은 유지됩니다. 두 사람은 다른 중계기를 동시에 복구할 수 있습니다.
- 레벨 완료 시 체력 8, 회복키트 8, 해금된 유한 탄약 15%를 보급하고 강화 3개 중 하나를 고릅니다.
- 정비 시간은 8초입니다. F(모바일은 준비 버튼)를 누르면 싱글은 즉시 시작하고, 협동은 두 사람 모두 준비한 뒤 시작합니다.
- 10레벨마다 탈출할 수 있습니다. 협동 탈출은 두 사람 모두 탈출 버튼을 눌러야 성립합니다.

## 온라인 협동 규칙

- 한 방에 정확히 2명만 입장합니다. 두 사람이 모두 준비해야 시작할 수 있습니다.
- 적·체력·피해·탄약·목표·점수·보상은 서버가 판정합니다. 전장은 공유하며 강화는 각자 선택합니다.
- 협동은 적 투입량을 싱글의 약 1.55배로 조정합니다. 적 수 상한 때문에 정확한 비율은 달라질 수 있습니다.
- 아군에게 총격·화염 피해는 없습니다. 자신의 화염·폭발물과 적의 폭발에는 피해를 입을 수 있습니다.
- 친구가 쓰러지면 가까이 다가가 **E를 약 1.15초간** 누르면 체력 40%로 부활합니다.
  부활에는 키트가 들지 않습니다. 살아 있는 친구 치료에는 자신의 회복키트를 씁니다.
- 두 사람 모두 쓰러지면 게임 오버입니다. 한 사람이 목표를 끝내면 쓰러진 친구도 다음 정비에 부활합니다.
- 업그레이드는 25초 안에 고릅니다. 미선택 시 제시된 첫 보상이 자동 적용됩니다.
- ESC는 자신의 설정만 엽니다. **온라인 전투는 계속됩니다.**
- 연결이 끊기면 방 전체 진행을 최대 **2분** 멈춥니다. 같은 탭을 새로고침하면 세션을 복구합니다.
  재접속 후 PC에서는 계속하기를 눌러 조작을 재개할 수 있습니다.
- 의도적으로 방을 나가거나 2분을 초과하면 해당 런이 종료됩니다.
- 서버를 종료·재시작하면 진행 중인 방은 사라집니다. 방 상태는 메모리에 저장됩니다.

## 조작

| 동작 | 기본 입력 |
|---|---|
| 이동 / 달리기 / 점프 | WASD / Shift / Space |
| 사격 / 조준 | 마우스 왼쪽 / 오른쪽 |
| 무기 변경 / 재장전 | 1~9 또는 휠 / R |
| 자기 회복 / 아군 치료·부활 | E / 친구 가까이에서 E 길게 |
| 중계기 복구 | 가까이에서 F 길게 |

모바일은 가로 화면에서 이동 스틱·발사·조준·목표·회복 터치키를 사용합니다.
키보드와 마우스 바인딩, 터치키 위치·감도·크기, 시야각, 화면 흔들림,
조명 깜빡임, 고대비 표시를 설정할 수 있습니다.
느린 PC에서는 그래픽을 **초저사양 / 사무용 PC**로 낮추세요.

## 사운드 1.2

메인 화면의 **사운드 설정**, 또는 게임 중 **ESC → 사운드 설정**에서 조절합니다.

- 전체·효과음·배경 음악·환경음의 음량을 각각 저장합니다.
- **좌우 · 효과음 확인**: 왼쪽 → 오른쪽 → 권총 → 금속 타격 순서로 재생합니다.
- **권장 음량으로**: 전체 100%, 효과음 85%, 음악 65%, 환경음 60%로 복원합니다.
- 균형 / 이어폰 / 야간 모드를 제공합니다. 야간은 총격·피격·폭발과 공간 울림을 낮춰 작은 안내음과의 차이를 줄입니다.
- 적과 동료의 총성·발소리·공격음은 카메라 방향, 거리, 벽에 따라 달라집니다. 초저사양에서도 위험을 알리는 발소리를 유지합니다.
- 무기별 발사·재장전·탄피/기계음, 타격·폭발·보스 공격 예고음을 보강했습니다.
- 레벨 시작·목표 완료·중계기·정비 카운트다운·동료 쓰러짐/부활·탈출을 서로 다른 소리로 구분합니다.
- 음악은 탐색·전투·위험 상태에 맞춰 바뀝니다. 총격·경고음 때 음악을 잠시 낮춥니다.
- 소리는 게임 안에서 합성합니다. 별도 음원 다운로드나 외부 서비스 없이 오프라인에서도 재생됩니다.

기존 저장 음량은 유지합니다. 소리가 작거나 꺼져 있으면 먼저 **권장 음량으로**를 누르세요.
브라우저가 소리 재생을 막거나 기기 전환 후 멈췄다면 **좌우 · 효과음 확인**을 눌러 다시 켤 수 있습니다.
전체 음량이 0%이면 테스트음도 나오지 않습니다. 이 경우 화면에 음량 안내를 표시합니다.

## 개발·검증

```bash
npm ci
npm run check
npm start
```

- `npm run check`: 소스 문법 검사 → 회귀/실제 소켓 테스트 → 브라우저 번들 생성
- `npm test`: 레벨 판정, 이동·입력·내비게이션, 2인 입장·피해·보상·부활·재접속 테스트
- 수정 후에는 `npm run build`로 `client/game.bundle.js`를 갱신합니다.
- 브라우저 번들은 완성본이 포함되어 있으므로 플레이만 할 때 빌드는 필요 없습니다.

세부 변경과 검증 범위는 `CHANGELOG.md`, `QA_REPORT.md`에 있습니다.
